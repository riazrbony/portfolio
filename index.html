Turning emergency searches into phone calls a 24/7 tow business can count

iFAST sells urgent help: towing, jump starts, lockouts and mobile tire service across the GTA. Customers don't fill in forms; they tap to call or message on WhatsApp. So the job was to buy the right searches and to count every call and message as a lead.

How I did it

  1. Built Search campaigns by service (towing, battery, tires, lockout) so budget and ad copy match what the driver typed.
  2. Targeted the GTA service area, ran ads 24/7, and added negative keywords to cut job seekers and DIY searches.
  3. Tracked every tel: link and WhatsApp button in Google Tag Manager as GA4 events, marked them as key events, and imported them into Google Ads as conversions.
  4. Read Search Console queries to find services and cities people searched for, and fed them back into ads and page copy.

What I'd do next

  • Add LocalBusiness / AutomotiveBusiness schema with service areas and opening hours.
  • Build city pages for Mississauga, Brampton, Markham and Vaughan, which the site's description names but doesn't have pages for yet.
  • Add call-length conversions so short misdials don't count as leads.

A WooCommerce store selling smartphones bundled with mobile plans

A pilot partnership between Chaldal and Robi, one of Bangladesh's largest mobile operators, to sell smartphones bundled with Robi plans. I created the WooCommerce site from scratch and kept it running: catalog, bundles, checkout and the custom plugins that made phone-plus-plan sales work. The pilot grew into a store that ran for about two and a half years.

What I built

  • Phone catalog with variations (model, storage, colour) and plan bundles attached to each handset.
  • Custom PHP plugins for bundle logic and order handling the stock WooCommerce setup couldn't do.
  • Python scripts for product and stock data upkeep.
  • Mobile-first, responsive storefront for customers shopping on phones.

How it grew

  1. Months 1–2: Google Ads and Facebook Ads on a $300/week budget, bidding for leads to build traffic and awareness.
  2. Month 3: first sales, 2 at first, then 10–12 phone-and-plan bundles. Stock of 9–11 devices at a time held sales back.
  3. Brand partnerships: promotions with phone brands lifted the stock limit and the offer.
  4. The breakthrough: organic search rankings, plus two Google Ads campaigns aimed at buyers outside Dhaka and Chittagong, where phone deals were harder to find.

My own project: learners book lessons with approved instructors, track their hours, and get ready for the road test. I'm planning the site structure for SEO before writing any pages, so every page has a search it's meant to rank for.

Build plan

  • Student dashboard for logged lesson hours.
  • G1 practice quiz as a free tool that attracts links and searches.

SEO and tracking plan

  • DrivingSchool, FAQPage and Review schema.
  • GA4 booking funnel: postal_code_entered → package_selected → purchase.
How I measure

The same five steps on every site, so SEO and ads results are counted, not guessed

1. Plan

Agree what counts as a win: a quote request, a call, a datasheet download. Write it down as a short measurement plan.

2. Tag

Push clean dataLayer events from the site; fire GA4 tags from Google Tag Manager, never hard-coded.

3. Count

Mark the important events as GA4 key events and import them into Google Ads as conversions.

4. Find

Search Console for queries, indexing and Core Web Vitals; GA4 funnels to see where people drop off.

5. Fix & report

Ship the change, then show the before and after in a Looker Studio report the sales team can read.

B2B Spec Sheet & Quote: a WooCommerce plugin for electronics catalogs

For buyers

A specifications tab, a datasheet download and a "Request a quote" dialog on every product. Accessible, mobile-friendly, no jQuery.

For search

Adds the part number, every spec and the datasheet to WooCommerce's Product schema, so Google can read the technical data.

For sales & marketing

Quotes are saved, emailed, sent to a CRM webhook and available through a REST API. GA4 events (quote_start, generate_lead) go through GTM.

// Add specs + MPN to WooCommerce's Product JSON-LD
add_filter( 'woocommerce_structured_data_product', function ( $markup, $product ) {
    $id = $product->get_id();
    if ( $mpn = get_post_meta( $id, '_b2bsq_mpn', true ) ) {
        $markup['mpn'] = $mpn;
    }
    foreach ( B2BSQ_Plugin::get_specs( $id ) as $row ) {
        $markup['additionalProperty'][] = array(
            '@type' => 'PropertyValue',
            'name'  => $row['label'],   // e.g. "Impedance"
            'value' => $row['value'],   // e.g. "50 Ω"
        );
    }
    return $markup;
}, 10, 2 );

Simplified from the plugin's extend_product_schema() method. Also includes: nonce check, honeypot and rate limit on the quote API, sanitised input and escaped output.
